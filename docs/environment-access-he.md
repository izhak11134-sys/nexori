# גישה בסביבת העבודה — 10 באוקטובר 2026

סביבת העבודה משתמשת ברשת מוגבלת עם רשימת דומיינים מותרים ופרוקסי. זו הגדרה של סביבת הפיתוח, ואינה תקלה שהוכחה בקוד NEXORI או בחשבון Firebase. הרשאה כללית לכלי להשתמש ברשת אינה בהכרח משנה את רשימת הדומיינים. שמירת דראפט הגדרות אינה מפעילה אותו אוטומטית.

## מה עובד בפועל

- קוד האתר, בנייה ותצוגה מקומית נבדקו בסביבה. עדכוני GitHub משתמשים באימות הקיים של הפלטפורמה.
- מסמכי Firebase וקובצי האמולטורים הרשמיים נגישים כעת. הכלי בדק את סכומי הביקורת של הקבצים.
- ארבע בדיקות Auth, Firestore, Storage ו־Functions עברו בפרויקט `demo-nexori`: הרשאות, תמונות, שמירה, פרסום תוכן ושחזור. שירותי הפרויקט האמיתי עדיין לא אומתו.
- דוח AJA הורד ונקרא; דפי Amazon Associates ו־dentsu נפתחו. זו התקדמות בגישה ולא השלמת מחקר השותפים.

## מה תוקן ומה נשאר

Firebase CLI 15.33 שלח גם בקשות HTTP מקומיות דרך ProxyAgent למרות הגדרת `NO_PROXY`. תיקון סביבת ההרצה מסיר את ה־dispatcher רק עבור HTTP ל־localhost, ל־127.0.0.1 ול־IPv6 loopback. הוא אינו משנה פרוקסי או הרשאות של יעדים באינטרנט. הוראות יצירת התיקון, נתיבי המטמון והפעלת האמולטורים נשמרו בדראפט הסביבה; הפקודה המתועדת נמצאת ב־`firebase-editor-checks.md`.

Sony החזיר דף Access Denied של האתר עצמו. דף Crunchyroll שנשלף דורש טעינת תוכן בצד הלקוח; תגובת 200 לא הספיקה לקריאת הכתבה. דוח dentsu מפנה ל־`assets-eu-01.kc-usercontent.com`; יעד זה נוסף לדראפט תוך שימור ההרשאות הקיימות, אך ה־PDF עדיין לא נקרא בהצלחה. אלו מצבים שונים, ואין להסיק שכל חסימה נפתרת באותה הגדרה.

לפי תשובת כלי ההגדרות, יש לסקור ולשמור את שינויי הגדרות הסביבה ואז לפרסם את **סביבת העבודה** כדי להפעיל את התצורה לשימוש חוזר. אין מדובר בפרסום האתר לציבור. לא פורסם האתר, לא הופעל חיוב, ולא נבחר מיקום Firestore חדש. אין כרגע ראיה ששינוי מודל או פתיחת צ׳אט חדש נחוצים לפתרון המגבלות שנמצאו.
