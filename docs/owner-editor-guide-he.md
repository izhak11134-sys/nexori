# NEXORI — שימוש בכפתורי העריכה

יש עכשיו שני קבצים נפרדים:

- **NEXORI-editor.html** — סביבת עריכה עבורך, עם כפתורים בעברית.
- **NEXORI.html** — תצוגת האתר למבקרים, ללא כלי העריכה.

העורך פועל מקומית בדפדפן ואינו פאנל ניהול של אתר חי. אין בו חשבונות, התחברות או הרשאות שרת, והוא אינו משנה אוטומטית קבצים במחשב, ב-GitHub או אצל ספק אחסון. מקור הכלי יכול להיות ציבורי בלי לאפשר לאחרים לערוך אתר משותף: כל עותק עורך רק את הטיוטה בדפדפן של מי שפתח אותו. אין להציג הסתרת כפתורים כאבטחה של מערכת ניהול.

## התחלה

1. הורד את **NEXORI-editor.html** מ-GitHub באמצעות Download raw file. שמור את הקובץ, ואז פתח אותו בדפדפן מודרני. עמוד הקוד של GitHub אינו מפעיל את האתר.
2. עבור לכרטיסייה הרצויה ולחץ על **עריכה**. אפשר גם לבחור אותה מתוך **כל הכרטיסיות…** בסרגל התחתון וללחוץ **עריכת הבחירה**.
3. שנה רק את השדות הרצויים. הכותרת והתמונה הן שדות נפרדים.
4. העלה תמונת PNG, JPEG או WebP, עד 2MB ובממדים של עד 8000×8000. השתמש בתמונה שיש לך רשות להשתמש בה; העורך אינו מאמת זכויות.
5. לחץ **שמירת טיוטה** כדי להחיל את העריכה. **ביטול** או Escape סוגרים ללא שמירת השינויים בחלון.
6. **איפוס הכרטיס לברירת המחדל** ממלא מחדש את החלון. השינוי חל רק לאחר שמירת טיוטה; אפשר עדיין לבטל.
7. **תצוגה מקדימה** מסתירה את כפתורי העריכה. **חזרה לעריכה** מציגה אותם שוב.

## דוגמת Dragon Ball

לחץ על Dragon Ball באתר, ואז על עריכה בחלק העליון של העמוד. בחלון תמצא שדות נפרדים:

- כותרת הכרטיסייה, התיאור הקצר ורקע הכרטיסייה — לתצוגה שממנה נכנסים.
- כותרת העמוד הפנימי, תיאור העמוד ורקע העמוד — לתצוגה שאליה נכנסים.

החלפת **רקע העמוד הפנימי** אינה משנה כותרת, ואינה מחליפה את הרקע של הכרטיסייה החיצונית. שינוי כותרת העמוד אינו משנה את שם הכרטיסייה החיצונית. מזהה הסדרה והקישורים נשארים יציבים גם אם כותרת התצוגה משתנה.

## מה אפשר לערוך

- כרטיסי המוצרים/הקונספטים ועמודי הפרטים: שם, תיאור, תווית סוג, קטגוריה, תת־סוג, בדיקות לפני קנייה, תמונה ותיאור נגיש.
- קטגוריות ותתי־סוגים: כותרת, תיאור ורקע.
- עולמות האנימה: כרטיסייה ועמוד פנימי בנפרד.
- כרטיסי המדריכים: כותרת, תקציר, תווית, זמן קריאה ותמונה; הכותרת והתמונה מתעדכנות גם בעמוד המדריך. גוף המאמר המלא אינו עורך טקסט חופשי בשלב הזה.
- הבאנר הראשי: שלוש שורות הכותרת, התיאור והתמונה.
- כרטיסי ההמשך בדף הבית, כרטיסי אודות וכרטיסי המידע בדפי המדיניות.

העורך משנה רשומות קיימות. הוספת רשומות מוצר חדשות, הפעלת קישורי רכישה, מחירים, רישוי ומוצרים אמיתיים יושלמו בשלב בחירת המוצרים. השם/תמונה אינם הופכים קונספט למוצר מאומת. קישור לחנות והערות פרטיות בכרטיס מוצר הם שדות הכנה בלבד; אינם מופעלים כקישורי קנייה ואינם נכללים בקובץ המיוצא למבקרים.

## שמירה, גיבוי וייצוא

**שמירת טיוטה** משתמשת ב-localStorage בדפדפן תחת `nexori.owner-draft.v1`. השמירה עשויה להיות תלויה בדפדפן ובאופן פתיחת קובץ מקומי. ניקוי נתוני אתר, מצב פרטי, מעבר למכשיר/דפדפן אחר או אחסון מלא עלולים לגרום לאובדן טיוטה. אין להסתמך על הדפדפן כגיבוי יחיד.

- **גיבוי טיוטה** מוריד `NEXORI-draft.json`, כולל התמונות והשדות ששונו. הוא עשוי לכלול הערות הכנה פרטיות, ולכן יש לשמור אותו כקובץ עבודה ולא לפרסם אותו למבקרים.
- **טעינת גיבוי** מחליפה את הטיוטה הנוכחית בגיבוי שנבחר, לאחר בדיקת פורמט, שדות ותמונות. גבה את העבודה הנוכחית קודם אם תרצה לשמור גם אותה.
- **הורדת אתר מעודכן** מורידה `NEXORI.html` הכולל את הטקסטים והתמונות שנשמרו, ללא סרגל וכפתורי עריכה וללא הערות ההכנה הפרטיות או קישור החנות שבהכנה. זהו קובץ סטטי לשיתוף/בדיקה, לא פרסום לאינטרנט.

אם הודעת השמירה אומרת שהשינוי לא נשמר בדפדפן, הוא עדיין מוצג בזיכרון של החלון. הורד מיד גיבוי או אתר מעודכן לפני סגירת החלון. כדי להמשיך לערוך במכשיר אחר, פתח בו את קובץ העורך וייבא את הגיבוי.

כדי לשלב בהמשך את העריכות בקוד וב-GitHub, נשתמש בגיבוי הטיוטה. שינוי בדפדפן אינו commit. ייצוא האתר המיועד למבקרים אינו שומר בתוכו הערות פרטיות ואינו הופך אותו לעורך.

## תמונות והעיצוב הקיים

רקעים מותאמים משולבים עם שכבה כהה כדי לשמור על קריאות. עדיין צריך לבדוק ניגודיות וטקסט אחרי כל תמונה חדשה. אפקט הלהב והסלעים ממוקם לפי הבאנר המקורי; החלפת תמונת הבאנר מסתירה את האפקטים האלה כדי שלא יופיעו במקום שגוי. החזרת התמונה המקורית מחזירה אותם.

לא הוספו trackers, העלאת תמונות לשרת או שליחת הודעות. התמונות מוטמעות בטיוטה ובייצוא. HTML, SVG וקישורי תמונה חיצוניים אינם נתמכים כהעלאות בעורך.

## פיתוח

להפעלת העורך בסביבת הפיתוח: הרץ `npm run dev -- --port 5173 --strictPort` ופתח את `/editor.html`. העורך משתמש בניווט hash. ייצוא HTML עצמי זמין בקובץ העורך שנוצר על ידי `npm run build:html` או `npm run build`; בסביבת הפיתוח אפשר לגבות/לייבא JSON.

הפריסה הציבורית נשארת `dist/`, שאינו כולל את קובץ העורך. מערכת ניהול עתידית שמעדכנת אתר חי תדרוש אימות משתמשים, הרשאות, אחסון וקוד שרת — היא אינה חלק מכלי הטיוטה המקומי הזה.
