# תיקון מגבלת ההידור של כללי Firestore

צילום תגובת API של Firebase הציג INVALID_ARGUMENT וקידומת Total size of compiled exe… בבקשת פרסום הכללים. בדיקת גודל המקור בלבד לא הספיקה, והאמולטור קיבל גרסה שהפרסום בשרת דחה.

הוחלפו 53 פונקציות אימות מוצר נפרדות בפונקציה אחת של 16 בדיקות. מזהי המוצרים לכל מקטע מועברים כנתונים קבועים מתוך הסכמה; כל מקטע מכסה בדיוק אותם מזהים כמו קודם. לא השתנו מזהי מסמכים, מבנה טיוטות, חשבון מנהל, בדיקת אימות דוא״ל, כללי תמונות או קוד האתר. האתר הקיים תואם לכללים החדשים.

מדידה מקומית באמצעות FirebaseRulesProtoCompiler שמצורף לאמולטור Firestore 1.22.0: המקור הישן 169061 בתים, AST מהודר מקומי 710850 בתים; המקור המצומצם 75332 בתים, AST מהודר מקומי 234343 בתים, ללא שגיאות או אזהרות. המדידה המקומית אינה פרסום או בדיקה של המהדר בענן. הפרסום בפועל עדיין נעשה במסך Firebase של הבעלים.

בדיקות: תשע בדיקות אינטגרציה מול אמולטור Auth/Firestore, כולל כל 840 המוצרים, כל 16 עמדות האימות בפונקציה המצומצמת, מקטעים לא מוכרים, מניעת גישה למשתמש זר, תמונות פרטיות, הפרדת מידע פרטי מפרסום, היסטוריה וביטול מנהל.

בדיקת תקציב ההידור המקומי (Java 21, לאחר התקנת האמולטור):

```sh
java -cp "$FIREBASE_EMULATORS_PATH/cloud-firestore-emulator-v1.22.0.jar" scripts/check-firestore-compiled-size.java firestore.rules
```

הכלי נכשל בשגיאת הידור או AST מעל 245000 בתים; זהו סף שמרני למדידה המקומית ולא התחייבות לגבי המהדר בשירות.
