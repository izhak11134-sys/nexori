# NEXORI — מסלול Spark חינמי בלבד

עודכן 10 באוקטובר 2026. דרישת המשתמש: שירותים חינמיים בלבד, ללא אמצעי תשלום או Cloud Billing. אין לשדרג ל־Blaze, לפרוס Functions או להפעיל Storage.

## המצב הנוכחי

המשתמש אישר יצירת Firestore Standard במסד `(default)` באזור Iowa (`us-central1`) ושמירת מסמך `admins/<Auth UID>` עם `active` מסוג Boolean וערך `true`. Email/Password הופעל והגדרות Web נשמרו מקומית. אלו דיווחי משתמש; מסלול החשבון, כללי הענן, אימות הדוא״ל והחיבור האמיתי טרם אומתו על ידי הסוכן. האתר לא פורסם.

## המערכת שהותאמה

היישום הראשי משתמש ב־Authentication וב־Firestore בלבד. מנהל עם דוא״ל מאומת והרשאת UID פעילה עורך את כל הכרטיסיות הקיימות בתוך האתר. טיוטות ותמונות חדשות פרטיות; החלת שינויים ושחזור יוצרים גרסאות ציבוריות מבוקרות. בדיקת מספר גרסה מונעת דריסה של שינוי חדש ממכשיר אחר. הערות הכנה וקישורי חנויות פרטיים אינם נכללים בגרסה הציבורית. כותרות ותמונות הכרטיס והעמוד הפנימי עצמאיות בכל ששת עולמות האנימה.

אין שימוש פעיל ב־Cloud Functions או Cloud Storage. התיקייה `functions/`, כללי Storage והבדיקות הישנות נשארו כתיעוד היסטורי; הם אינם כלולים בהפעלת האמולטורים, בדיקות Spark או תצורת הפריסה הפעילה.

תמונות PNG/JPEG/WebP עד 2MiB מפוענחות ומומרות בדפדפן ל־WebP, עם צלע מרבית של 1600 פיקסלים ועד 192KiB לתמונה. קובצי התמונה נשמרים בשדות Bytes במסמכי Firestore נפרדים ומוצגים באמצעות כתובות Blob מקומיות. ההקטנה עשויה להפחית איכות; התמונות הקיימות במאגר נשארות קבצים סטטיים. גבול הטקסט בטיוטה הוא 600KiB. אין אימות פיקסלים בשרת; כללי הענן אוכפים הרשאות, גודל, סוג שדה, מבנה ותהליך גרסאות, והלקוח מבצע אימות תוכן ופענוח תמונות.

## הרשאות וגרסאות

`firestore.rules` נוצר מהכרטיסיות והשדות המורשים באמצעות `npm run firebase:sync`. שמירה מאמתת שמונה מסמכי קבוצות בלתי ניתנים לשינוי לפני עדכון ראש הטיוטה. החלה מאמתת קבוצות ציבוריות ומעתיקה תמונות פרטיות; מסמך ציבורי, היסטוריה וסמן שחרור נשמרים אטומית. תמונות וקבוצות שהוכנו מראש אינן נגישות לציבור עד סמן השחרור. החלוקה מאפשרת לאמת את כל 81 הכרטיסיות במסגרת מגבלות בדיקות הכללים של Firestore. יש ליצור ולבדוק כללים מחדש כשמרחיבים את הסכמה.

הכללים מונעים הענקת הרשאה עצמית, עריכת תוכן על ידי מבקרים, שינוי תמונות וגרסאות קיימות, וקריאת טיוטות או תמונות פרטיות ללא ההרשאה המתאימה. מנהל שנשללה הרשאתו אינו יכול לשמור. Production mode הוא מצב כללים התחלתי, ולא מסלול חיוב או פרסום אתר.

## מכסות וניהול לפני ההשקה

Spark אינו חיוב לפי שימוש; אין לחבר חיוב. חריגה ממכסות עשויה להשבית פעולות לפי כללי השירות. זהו פתרון פיתוח חינמי מוגבל, לא הבטחה לתעבורה בלתי מוגבלת. תמונות, גרסאות, קריאות מבקרים ובדיקות מסמכים מתוך כללי הגישה משתמשים במכסות Firestore. כל שמירה יוצרת שמונה מסמכי קבוצות וראש טיוטה, בנוסף לתמונות; החלה יוצרת קבוצות, תמונות ציבוריות והיסטוריה. מטמון תמונות קיים בזיכרון הדפדפן בלבד. גרסאות ישנות ומסמכים שהוכנו לפני פעולה שנכשלה אינם נמחקים אוטומטית. יש להגדיר מדיניות שמירה וניקוי דרך כלי מנהל מורשה לפני ההשקה ולעקוב ב־Usage.

השלב הבא: העתקת כללי Firestore המעודכנים לקונסול לפי `firebase-console-setup-he.md`, אימות דוא״ל ובדיקת כניסה/שמירה אמיתית. פעולת Publish במסך Rules מפרסמת כללי גישה בלבד; היא אינה מעלה את האתר לאוויר. בדיקות האמולטור אינן מחליפות בדיקות בפרויקט האמיתי.
