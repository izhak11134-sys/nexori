NEXORI — הפעלה מקומית ב־Windows

קובץ החילוץ האוטומטי הוסר בעקבות דיווח על התראת אנטי־וירוס.
אין לכבות הגנה, להוסיף החרגה או לשחזר קובץ שנחסם.
שם האיום והקובץ שנחסם עדיין נדרשים לאבחון. שינוי החבילה אינו אישור מסריקת אנטי־וירוס.

1. Node.js LTS בגרסה 22 או חדשה יותר נדרש להפעלה; אם כבר הותקן, אין צורך בהתקנה נוספת.
2. הורד את חבילת האתר העדכנית, לחץ עליה לחיצה ימנית ובחר חלץ הכול / Extract All.
3. בתיקייה שחולצה פתח NEXORI-Windows. ודא שאתה רואה את start-local.mjs ואת התיקייה site.
   אין להפעיל מתוך חלון ה־ZIP ואין לפתוח את site/index.html ישירות.
4. בתוך התיקייה הרגילה לחץ על שורת הכתובת של סייר הקבצים, הקלד cmd ולחץ Enter.
   ייפתח חלון שורת פקודה בתיקייה הזו. הקלד בו:

   node start-local.mjs

5. פתח בדפדפן http://localhost:5173/admin.
   השאר את חלון שורת הפקודה פתוח בזמן העבודה. לסיום לחץ Ctrl+C.

החבילה אינה כוללת מפעילי CMD/BAT, חילוץ אוטומטי או פתיחת דפדפן אוטומטית.
השרת קורא את קובצי site ומגיש אותם בחיבור מקומי בלבד. הוא אינו מתקין דבר,
אינו מפעיל תהליכים אחרים ואינו משנה את הגדרות ההגנה.
אם גם החבילה הזו נחסמת, עצור ושלח את שם האיום ושם הקובץ מתוך היסטוריית ההגנה.

לפני הכניסה הראשונה:
Firebase Console > Authentication > Settings > Authorized domains
אם localhost אינו מופיע, לחץ Add domain והוסף localhost בלבד, ללא http או פורט.
אין לשנות את מסלול Spark, להוסיף כרטיס אשראי או להפעיל שירותים נוספים.

כניסה:
השתמש בכתובת הדוא״ל של חשבון המנהל ובסיסמה שקבעת ב־Firebase Authentication.
אם מופיעה דרישה לאימות דוא״ל, לחץ ״שליחת הודעת אימות״, פתח את הקישור
בהודעה שהגיעה לדוא״ל, התנתק והתחבר שוב.
אחרי הופעת ״מצב עריכה פעיל״ אפשר לנווט באתר וללחוץ ״עריכה״ ליד הכרטיסיות.

״שמירת טיוטה״ שומרת תוכן בפרויקט Firebase האמיתי, והוא נשאר פרטי למנהל.
״החלת השינויים באתר״ מעדכנת את התוכן הציבורי בפרויקט Firebase הזה.
ההפעלה המקומית אינה מעלה את האתר ל־Hosting. האתר מוגש רק במחשב שלך.
נדרש חיבור אינטרנט לכניסה ולשמירה. תמונות וגרסאות משתמשות במכסות Spark.
הגדרות Firebase Web הציבוריות כבר כלולות; אין בחבילה סיסמה או מפתח מנהל.
הכניסה וההרשאות בפרויקט שלך עדיין צריכות בדיקה. אין לשלוח סיסמה בצ׳אט.
